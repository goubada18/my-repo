### 切枪位置漂移真根因：世界 AABB 中心膨胀（2026-08-16 03:40 已修）
- **现象**：切枪后模型位置漂移（每次切都变），M82 没用完美镜头位置。
- **真根因**：`fp_viewmodel_player.gd _compute_model_center` 用【世界 AABB】8角点 expand 取中心。模型带旋转(0,1.57,0.04)+镜像(1,1,-1)时，轴对齐 AABB 在旋转后中心≠几何真中心；且相机带位移/旋转（游戏里 CameraPivot 下）进一步偏移。探针挂 identity 相机碰巧相等 → 误判"正确"。运行时实测 center 从 0.598 漂到 0.668 → `fp_gun_pos - center` 偏离 gun_pos → 摆放错。
- **修复**：center 改【模型本地空间】计算（model_inv * 各网格 global → 本地 AABB 合并），只依赖几何+骨骼 rest pose，与相机/模型变换完全无关。实测相机带变换+模型 rotation+draw 动画中，center 恒 = (0.597666,-0.212363,1.213048)（与参考一致）。另加 `_center_dirty` 缓存：center 只在模型加载(rest pose)算一次，动画中不重算（双保险）。
- **验证**：端到端 M82 两次切枪 center/摆放完全一致 (-0.0162,-0.0272,-0.1304)；`fp_gun_pos - center = (0.10,-0.20,-0.70)` = gun_pos ✓ 完美位置成立。回归错误 0。
- **教训**：skinned mesh 的几何中心必须用本地空间算；世界 AABB 在旋转/镜像下中心不可信（此前多轮"位置不对"可能同源）。
