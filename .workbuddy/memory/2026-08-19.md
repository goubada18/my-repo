## 修复：编辑器崩溃(probe_fbx_skel.gd) + 预览动画不播
- **崩溃根因**：`tools/probe_fbx_skel.gd`（历史遗留探针）第27/33行 `var x := load(...).instantiate()` 无法推断类型 → 编辑器全量扫描脚本时报 Parse Error 崩溃。修：改显式类型 `var fbx_inst: Node = ...`。已全项目扫描确认无其他 parse error。
- **动画不播根因（编辑器内）**：Godot 编辑器默认**不 tick AnimationPlayer**，@tool 脚本 `_ready` 里 `play()` 后时间轴不动；且 glTF 导入动画 `loop_mode=0` 无循环，待机播完即停。修：`vm_preview_control.gd` 加 `_process(delta)` 编辑器内手动 `_ap.advance(delta)`；`_play()` 统一设 idle 循环(loop_mode=1)、动作单次(loop=0)。

- 经验：**headless 能播 ≠ 编辑器能播**——编辑器 @tool 动画必须手动 advance；探针里 `_init` 调异步 `_run` 必须 `await`，否则 quit() 截断输出。

## 编辑器崩溃排查全记录（2026-08-19 17:00-17:29，已解决）
