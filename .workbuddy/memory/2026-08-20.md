## 修订2（同日·真根因）：Panel 不是容器 → 列表塌陷/不居中
- **根因（务必记住）**：`Panel` 是普通 Control **不是容器**，不给子节点做布局。
  原 `menu_base._make_panel` 与 `settings_menu._build_ui` 都把 `MarginContainer` 塞进 `Panel`
  → pad 只拿到"最小尺寸"并钉在左上角 → ①内容不居中 ②`ItemList` 最小高度为 0 被压成 0 高
  → **地图/角色"没有选项条"**（其实控件在、只是 0 像素高）③ESC 菜单又小又偏。
  **修复：改用 `PanelContainer`**（真容器，会把子节点拉满自身区域）。
- `menu_base.gd` 重写层级：bg → MarginContainer(外边距) → **PanelContainer**(卡片) → MarginContainer(内边距)
  → VBox(主列：标题 + row) → HBox(row: 左弹性空白 / 限宽内容列 / 右弹性空白) 实现水平居中。
  新增工厂：`_content_width()`(屏宽55%，≤760*s，≥320)、`_add_hint()`、**`_make_list()`（关键：给 ItemList
  `custom_minimum_size.y = max(vh*0.30, 170*s)`，否则仍可能塌成 0 高）**。`_on_resize` 改 remove_child 再 queue_free（避免同帧新旧 UI 重叠）。
- `settings_menu.gd`（游戏内 ESC）重写为响应式：同样 PanelContainer + 按 `_ui_scale()` 缩放，
  卡片宽 `clamp(vw*0.30, 340, 620*s)` 高度由内容定；连 `size_changed` 重建；`_on_main_menu_pressed` 补 `MOUSE_MODE_VISIBLE`。
- `settings_screen.gd`：新增 `_ids: Array[String]` 行索引→角色 id 映射（替代重复 load registry 反查），未选过默认高亮首个。
- `map_select.gd`：常量化 `DEFAULT_MAP_NAME/PATH`。

### 验证铁律补充（headless UI 布局测量）
- **headless 主视口是 64x64 哑窗口**，忽略 project.godot 的 1920x1080 → 直接测主视口里的控件，
  "未居中"全是假报（320px 控件塞不进 64px 视口）。
- 正解：探针里建 `SubViewport` 并设 `size = 目标分辨率`，把界面 `add_child` 进去，
  Control 的 `get_viewport_rect()` 即取 SubViewport 尺寸，布局按真实分辨率计算；等 2 帧后读 `get_global_rect()`。
- 实测结果（1280x720 / 1920x1080 / 2560x1440 × 4 界面，FAIL=0）：所有控件 center_x 精确 = 视口一半；
  卡片 1200→1800→2400 随屏缩放；地图列表高 282/424/567，角色列表高 360/541/723(items=2)。

## 修订3（同日）：SWAT 枪飘天/崩溃 + SWAT 无狙击枪
### Bug #2 根因（SWAT AK 飘天，切枪一次复原）
- `_setup_weapon_and_fp()`（player.gd ~3622）初始握持用**默认** `weapon_rig_config.tres`（飞虎队缩放 0.00026），
  但切枪路径 `_switch_to_weapon`（~741）用 `prepare_rig_config(base_cfg)` 把 `skeleton_space_scale` 覆写为**当前角色**缩放。
- SWAT 角色缩放 ≈0.0138（飞虎队 0.00026，差 ~53 倍）。初始用飞虎队缩放算握持偏移 → AK 枪漂到极大世界坐标（天上）。
  切一次枪走 prepare_rig_config 用对缩放 → 复原。FP 视图模型独立不受影响 → 仅 3P 飘。
- **修复**：`_setup_weapon_and_fp` 初始也走 `_weapon_system.prepare_rig_config(char_manager.get_active_asset().weapon_rig_config)`，
  与切枪路径一致。
- **验证**：探针量 SWAT 进游戏后 AK world 坐标(-0.416,2.377,0.415) vs 右手骨骼(-0.308,2.386,0.420)，距离 0.108（正确握在手上）。
  **该漂移也可能正是"选角色后进游戏崩溃"的诱因**（枪到极远/退化坐标 → 部分 GPU 驱动 Vulkan 设备丢失）。修复后崩溃诱因消除。
- 注意：`get_role_skeleton_scale()` 读的是 `char_manager.get_active_asset().weapon_rig_config.skeleton_space_scale`，
  所以角色资产**必须**带正确 `weapon_rig_config`（feihu=5_wcii5 / swat=8_rdfsl），否则仍退化到默认缩放。
